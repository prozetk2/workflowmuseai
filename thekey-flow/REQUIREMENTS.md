# TheKey.studio Flow — Requirements

1. Google Chrome or another Chromium browser with Manifest V3 extensions.
2. One of:
   - a Google account with access to Google Flow (flow.google.com) and an open Flow project, or
   - a Gemini API key with billing enabled for Veo.

No npm, pip, Docker or build step. Load this folder with "Load unpacked" in `chrome://extensions`.
The Flow integration follows Flow's current page and may need selector updates when Google changes it
(Settings → Check Flow page shows what still matches).
